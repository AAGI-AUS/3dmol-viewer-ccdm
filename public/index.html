Help & feedback

Questions, problems and ideas all go to the same place.

If you have a question or something to suggest, please open an issue on the project repository. That keeps everything in one place and means the answer is there for whoever asks next.

Worth raising as an issue:

  • Questions about the structures, sequences or interface residues shown here
  • Questions about the curated interaction data or the prediction scores
  • Anything about the project itself
  • Feature requests, and anything that looks wrong or broken
